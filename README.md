# CC8_2026_grupo2

Repositorio do Grupo 2 da tarefa final de Desafios de Programacao da turma do
8o semestre da Ciencia da Computacao.

## Partes

- `parte_01_varredura`: varredura e indexacao de arquivos.
- `parte_02_estruturas`: arvore AVL e ordenacao.
- `parte_03_documentos`: leitura de TXT, normalizacao, frequencia e relevancia.
- `parte_04_imagens_web`: imagens, pesquisa por metadados e interface web.

## Executar

```bash
pip install -r requirements.txt
python app.py
```

A interface abre em `http://127.0.0.1:5000`.
