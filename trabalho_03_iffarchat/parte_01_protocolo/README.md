# Parte 1 — Protocolo, transporte e segurança

**Arquivos:** protocolo.py, seguranca.py, transporte.py.

Codigos e formatos do enunciado, leitura de fluxo TCP, correlacao de respostas e FNV-1a.

Execute os testes a partir da raiz do projeto:

```bash
python -m unittest tests.test_parte_01 -v
```

Alguns testes de integracao atravessam varias partes. A divisao de responsabilidades e o criterio de equilibrio estao em [DIVISAO_EM_4_PARTES.md](../docs/DIVISAO_EM_4_PARTES.md).
